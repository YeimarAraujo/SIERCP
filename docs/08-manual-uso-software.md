## 1. Acceder al sistema

### 1.1. Iniciar sesión

**Requisitos previos:** Tener credenciales proporcionadas por tu institución. Usar un navegador compatible (Chrome, Firefox, Edge o Safari actualizados).

**Pasos:**

1. Abre tu navegador e ingresa la dirección web que te dio tu institución.
2. En la página principal, presiona el botón **"Iniciar sesión"** en la esquina superior derecha.
3. Aparecerá el formulario de inicio de sesión:

```
╔══════════════════════════════════╗
║                                  ║
║       INICIAR SESIÓN             ║
║                                  ║
║   Correo electrónico             ║
║   ┌──────────────────────────┐   ║
║   │                          │   ║
║   └──────────────────────────┘   ║
║                                  ║
║   Contraseña                     ║
║   ┌──────────────────────────┐   ║
║   │                          │   ║
║   └──────────────────────────┘   ║
║                                  ║
║   [ INICIAR SESIÓN ]             ║
║                                  ║
║   ¿Olvidaste tu contraseña?      ║
║                                  ║
╚══════════════════════════════════╝
```

4. Escribe tu **correo electrónico** y **contraseña**.
5. Presiona **"Iniciar sesión"**.

**Resultado esperado:** El sistema te llevará a tu panel de control según tu rol (Estudiante, Instructor o Administrador).

### 1.2. Cerrar sesión

1. Presiona tu **nombre o foto de perfil** en la esquina superior derecha.
2. Selecciona **"Cerrar sesión"** del menú desplegable.

### 2.2. Ver cursos

**Pasos:**

1. En el menú lateral (izquierda), presiona **"Cursos"**.
2. Verás la lista de cursos en los que estás inscrito.
3. Presiona un curso para ver su contenido (módulos, materiales y tu progreso).

**Unirse a un curso nuevo:**

1. Presiona el botón **"Unirse a curso"**.
2. Ingresa el **código de 6 caracteres** que te dio tu instructor.
3. Presiona **"Confirmar"**.

### 2.3. Ver historial

**Pasos:**

1. En el menú lateral, presiona **"Historial"**.
2. Verás un resumen de tus sesiones: total, aprobadas y puntuación promedio.
3. Desplázate para ver la lista de sesiones ordenadas por fecha.
4. Presiona cualquier sesión para ver el detalle.

### 2.4. Ver ranking

**Pasos:**

1. En el menú lateral, presiona **"Ranking"**.
2. Verás una tabla con las posiciones de los estudiantes de tu curso.
3. La tabla muestra: posición, nombre, puntuación promedio, sesiones totales y tendencia.

### 2.5. Editar perfil

**Pasos:**

1. En el menú lateral, presiona **"Perfil"**.
2. Puedes ver tus datos personales, estadísticas completas y certificados.
3. Presiona **"Editar"** para modificar tu información.

### 3.2. Gestionar cursos

**Crear un curso nuevo:**

**Pasos:**

1. En el menú lateral, presiona **"Cursos"**.
2. Presiona **"Crear curso"**.
3. Completa el formulario:
   - **Título del curso** (ej. "RCP Básico para Enfermería")
   - **Descripción** (opcional)
   - **Nivel:** Básico / Intermedio / Avanzado
   - **Modalidad:** Presencial / Virtual / Híbrida
   - **Duración estimada** en horas
4. Presiona **"Guardar"**.

**Resultado esperado:** El curso se crea y se genera un **código de invitación**. Puedes compartir este código con tus estudiantes o descargar el código QR.

**Agregar módulos a un curso:**

**Pasos:**

1. Abre el curso que creaste.
2. Presiona la pestaña **"Módulos"**.
3. Presiona **"Agregar módulo"**.
4. Selecciona el tipo:
   - **Teoría:** sube un video o PDF
   - **Evaluación:** crea preguntas de opción múltiple
   - **Práctica:** sesión RCP supervisada
   - **Certificación:** examen final
5. Completa los datos y presiona **"Guardar"**.

### 3.4. Evaluar estudiantes

**Pasos:**

1. En el menú lateral, presiona **"Evaluaciones"**.
2. Verás las evaluaciones pendientes y completadas.
3. Presiona una evaluación pendiente para calificarla.
4. Asigna una puntuación y agrega comentarios.
5. Presiona **"Guardar evaluación"**.

### 3.5. Generar reportes

**Pasos:**

1. En el menú lateral, presiona **"Reportes"**.
2. Selecciona el curso o estudiante que quieres evaluar.
3. Selecciona el rango de fechas.
4. Presiona **"Generar reporte"**.
5. Si necesitas el archivo, presiona **"Exportar CSV"**.

### 4.2. Gestionar usuarios

**Ver usuarios:**

**Pasos:**
1. En el menú lateral, presiona **"Usuarios"**.
2. Verás una tabla con todos los usuarios de la institución.
3. Usa los filtros para buscar por nombre, correo o rol.

**Crear un usuario nuevo:**

**Pasos:**
1. Presiona el botón **"Crear usuario"**.
2. Completa el formulario:
   - **Nombres y apellidos**
   - **Tipo de identificación** (CC, TI, CE, Pasaporte)
   - **Número de identificación**
   - **Correo electrónico**
   - **Teléfono**
   - **Rol:** Estudiante / Instructor
   - **Contraseña temporal**
   - **Sede** (opcional)
3. Presiona **"Guardar"**.

**Importar estudiantes desde archivo:**

**Pasos:**
1. Presiona **"Importar"**.
2. Descarga la plantilla CSV.
3. Completa los datos en Excel o Google Sheets.
4. Sube el archivo.
5. Revisa la vista previa y presiona **"Confirmar"**.

**Editar o desactivar un usuario:**

**Pasos:**
1. Presiona el nombre del usuario en la tabla.
2. En la pantalla de detalle, presiona **"Editar"**.
3. Modifica los datos necesarios.
4. Para desactivar la cuenta, presiona **"Desactivar cuenta"**.

### 4.3. Gestionar dispositivos (maniquíes)

**Ver dispositivos:**

**Pasos:**
1. En el menú lateral, presiona **"Dispositivos"**.
2. Verás la lista de maniquíes registrados con su estado.

**Registrar un maniquí nuevo:**

**Pasos:**
1. Presiona **"Agregar dispositivo"**.
2. Ingresa:
   - **Nombre:** un nombre para identificar el maniquí (ej. "Maniquí Sala 1")
   - **UUID:** el identificador único del ESP32
   - **API Key:** la clave del dispositivo
3. Presiona **"Guardar"**.

### 4.4. Gestionar sedes

**Pasos:**
1. En el menú lateral, presiona **"Sedes"**.
2. Presiona **"Crear sede"**.
3. Ingresa nombre, dirección y datos de contacto.
4. Presiona **"Guardar"**.
5. Puedes asignar usuarios y dispositivos a cada sede desde sus respectivas pantallas.

### 4.5. Ver configuración de la institución

**Pasos:**
1. En el menú lateral, presiona **"Configuración"**.
2. Verás los datos de tu institución y el plan actual.
3. Puedes modificar: nombre, logo, información de contacto.

## 6. Preguntas frecuentes

### Generales

**¿Qué navegador debo usar?**

Chrome 90+, Firefox 90+, Edge 90+ o Safari 15+. Mantén tu navegador actualizado para la mejor experiencia.

**¿Puedo acceder desde el celular?**

Sí, el dashboard web se adapta a pantallas de celular. Sin embargo, para entrenar RCP necesitas la app móvil.

**¿Los datos se actualizan solos?**

Sí. El dashboard se actualiza automáticamente. No necesitas refrescar la página manualmente.

### Para estudiantes

**¿Puedo ver mis resultados sin estar en la app?**

Sí. Todos tus resultados se guardan y puedes verlos desde el dashboard web en la sección "Historial".

**¿Mi instructor puede ver mis sesiones?**

Sí, si tienes un instructor asignado, él puede ver tus sesiones y resultados.

**¿Puedo descargar mis resultados?**

Sí, desde "Reportes" puedes exportar tus datos a CSV.

### Para instructores

**¿Puedo monitorear a varios estudiantes al mismo tiempo?**

Sí, puedes ver la lista de sesiones activas y cambiar entre ellas.

**¿Puedo crear un curso sin código de invitación?**

No. Todos los cursos generan automáticamente un código de invitación único.

**¿Los estudiantes necesitan crear su cuenta o yo los creo?**

Tú (o el administrador) deben crear las cuentas de los estudiantes. Ellos no pueden registrarse solos.

### Para administradores

**¿Cuántos usuarios puedo crear?**

Depende del plan de tu institución. Ve a "Configuración" para ver los límites de tu plan actual.

**¿Qué hago si un instructor no aparece?**

Los instructores se crean en estado "pendiente". Debes aprobarlos desde la lista de usuarios.

**¿Puedo transferir datos a otra institución?**

Sí, contacta al SUPER ADMIN de la plataforma para solicitar una migración de datos.
